# Prophet Cloud Critical Path v0.1

## Objective
Stand up Prophet Cloud Workspace with:
- SocioSphere control plane
- Matrix/chat collaboration
- Workroom runtime
- Agent mesh hosting
- Prophet Platform deployment substrate

## P0 Foundation (must complete first)
1. SocioSphere runtime APIs
2. Identity/Trust (mcp-a2a-zero-trust, Regis, Identity references)
3. Agent Registry
4. Policy Fabric
5. Evidence Ledger
6. AgentPlane
7. Compute Mesh
8. Model Router

## P1 Workspace Runtime
1. SourceOS Workspace bridge
2. Cloudshell Fog runtime
3. Workroom runtime
4. TurtleTerm operator path
5. Memory Mesh integration
6. Holmes/Sherlock query integration

## P2 Matrix/Chat
1. Matrix homeserver deployment
2. Workspace identity binding
3. Workroom room model
4. Agent participation model
5. Search and memory integration
6. Evidence receipt generation

## P3 Agent Mesh Hosting
1. AgentPlane control plane
2. Agent Machine lifecycle
3. Compute Mesh scheduling
4. Guardrail Fabric admission
5. Policy Fabric enforcement
6. Evidence Ledger receipts
7. Model Router execution routing

## P4 Product Surfaces
1. SocioProphet UI workspace shell
2. Service graph
3. Chat surface
4. Workroom surface
5. Agent control surface
6. GAIA
7. Academy
8. Professional Intelligence
9. Economic Coordination

## Deployment Matrix
Tier 0: SourceOS Boot / Runtime
Tier 1: Identity, Policy, Evidence
Tier 2: Agent Registry, AgentPlane, Compute Mesh
Tier 3: Workroom, Matrix, Search, Memory
Tier 4: Product Surfaces

## Success Condition
A user signs into Prophet Cloud Workspace, enters a Matrix-backed Workroom, invokes agents through AgentPlane, routes execution through Compute Mesh and Model Router, receives evidence-backed results, and can operate all services through the SocioProphet UI shell.
